# 大学物理期中复习：第 9–11 章

面向马文蔚等《物理学》第七版下册的振动、波动、光学复习讲义。2026-11-17 完整重写为“推导与应用版”：从模型、基本规律、推导到适用条件与解题步骤，补全公式之间的逻辑关系。

- 首页说明三章的共同主线；三章独立页面各有公式联系图、完整正文、章末题型及逐课件对应表。
- 40 个知识模块：第 9 章 12 个，第 10 章 11 个，第 11 章 17 个。含 5 个明确标注的教材目录补充模块。
- 18 道选择题、26 道计算题，共 44 题，全部有详细解析。
- 8 幅按公式或光路几何生成的 SVG 图。
- 公式使用 KaTeX 预排版，字体与样式本地托管，无第三方运行时依赖。
- 搜索、选择题判分、折叠解析、浏览器本地学习进度、手机悬浮目录及打印样式。

资料范围：用户提供的 26 份 PPT（448 页）均已渲染，按章节视觉核对公式、图示与题解；出版社公开目录用于核对第七版的章节结构。未取得教材全文，也没有老师单独的考试考纲。非线性系统、声波专节、液晶、几何光学列为“教材目录补充，PPT 未覆盖”，并注明公开原理参考。星级是复习建议，题目为自编或课件题型改编，非真题预测。

校核包括：KaTeX 严格预渲染、全部本地资源与锚点、数值题独立代入、受迫振动方程残差、一般初相驻波与边界条件、光路几何和偏振强度恒等式，以及电脑和手机浏览检查。原始 PPT 和内部审计图片不公开。

## 本地开发

需要 Node.js 22 或更新的兼容运行时。

```sh
npm ci
npm run build
npm run check
python -m http.server 8765 --directory docs
```

GitHub Pages 发布目录为 `codex/physics-review` 分支的 `/docs`。修改源内容后重新运行构建并提交 `docs` 输出。

正文源：`rewrite9.mjs`、`rewrite10.mjs`、`rewrite11.mjs`；跨章逻辑：`guide-intro.mjs`。
原 `content.mjs`、`chapter10.mjs`、`chapter11.mjs` 保留作结构辅助函数和已核对旧题的数据来源，不再直接构建旧版知识正文。
构建：`build.mjs`。模型图：`diagrams.mjs`。
课件文件名与页数元数据：`sources.json`，原始 PPT 未公开。

KaTeX 及其字体保留原许可证，见 `docs/vendor/KATEX-LICENSE.txt`。
